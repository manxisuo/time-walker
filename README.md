# 时空旅人 · Three.js

一个小人穿越 18 个世界的 3D 网页（星夜原野、霓虹之夜、金字塔、极光雪原、月球、星海、深海、原始森林、像素王国、琴键大道、素描世界、火山熔岩、时间齿轮城、梦境画廊、糖果王国、云端天空之城、水墨古风夜、微观世界），另有一个隐藏彩蛋。

- 纯前端，单文件 `index.html`，无需构建
- Three.js r128（通过 jsDelivr CDN 加载，需联网）
- 音效全部由 WebAudio 实时合成

## 操作
拖动转视角 · ← → 切换世界 · 空格暂停 · 点击/按键后开启音效

## 本地运行
直接用浏览器打开 `index.html` 即可。
